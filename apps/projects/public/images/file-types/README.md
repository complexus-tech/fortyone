# Comment attachment icons

These are unmodified official Microsoft assets, downloaded on 2026-10-16. Word,
Excel, and PowerPoint use standalone app symbols without an added document sheet,
letter overlay, border, or background. The letters and colored shapes within
each original asset are preserved. PDF uses the Fluent PDF file icon. No Google
Docs artwork is used. Assets are served locally, without a third-party request.

## Provenance

Microsoft's current [Word product page](https://www.microsoft.com/en-us/microsoft-365/word)
uses the FY26 Word, Excel, and PowerPoint assets below. These are the standalone
symbols from the [October 2025 redesign](https://microsoft.design/articles/fluid-forms-vibrant-colors/),
which retains the original letter plates. They replace the Fluent document-sheet
icons previously used here.

- `docx.svg`: [Word-Icon-FY26.svg](https://www.microsoft.com/content/dam/microsoft/bade/images/icons/en-us/m365-app-icons-fy26/Word-Icon-FY26.svg), for Word documents including `.doc`.
- `xlsx.svg`: [Excel-Icon-FY26.svg](https://www.microsoft.com/content/dam/microsoft/bade/images/icons/en-us/m365-app-icons-fy26/Excel-Icon-FY26.svg), for Excel spreadsheets including `.xls`.
- `pptx.svg`: [PowerPoint-Icon-FY26.svg](https://www.microsoft.com/content/dam/microsoft/bade/images/icons/en-us/m365-app-icons-fy26/PowerPoint-Icon-FY26.svg), for PowerPoint presentations including `.ppt`.
- `pdf.svg`: [Fluent PDF file icon](https://res.cdn.office.net/files/fabric-cdn-prod_20260917.001/assets/item-types/96/pdf.svg), from the CDN selected by the current official [Fluent file-type package](https://github.com/microsoft/fluentui-system-icons/blob/main/packages/react-icons-file-type/src/common/constants.ts).

The app SVGs have 48px view boxes; the PDF file icon has a 96px view box.
Rendering preserves their colors and proportions. The files contain no scripts
or external embedded resources. CSV, text, MP4, image fallbacks, and unknown files
use existing shared FortyOne icons. Archives are not accepted by the upload
validator and have no dedicated icon.
