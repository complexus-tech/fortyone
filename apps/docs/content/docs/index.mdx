FortyOne gives teams one place to turn goals, requests, and decisions into owned
work. Operations, marketing, product, engineering, customer support, field,
government, and leadership teams can shape the same core workflow around the
way they work.

These guides explain how to use FortyOne. Integration builders can switch to
the **API Reference** at the top of any page.

## The product at a glance

| Area                         | Use it for                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------------- |
| Goals and objectives         | Connect company or program direction to measurable outcomes and delivery work          |
| Requests and roadmaps        | Capture demand, make priorities visible, and communicate what happens next             |
| Teams and work items         | Own, prioritize, estimate, and track work through a shared workflow                    |
| Calendar and auto-scheduling | Make time for work around meetings, working hours, and existing commitments            |
| Maya                         | Ask questions, prepare plans, and apply reviewed changes with an explicit confirmation |
| Integrations                 | Keep conversations, code, designs, calendars, and FortyOne work connected              |

<Callout type="info" title="Your workspace may use different words">
  Administrators can rename core terms. If your workspace says “issues,”
  “tasks,” or another name, it still refers to the same underlying work item.
</Callout>
