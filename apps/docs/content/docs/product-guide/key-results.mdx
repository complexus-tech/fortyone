---
title: Key results
description: Measure whether an objective is producing the intended outcome.
icon: ChartNoAxesColumnIncreasing
---

A key result is a measurable signal attached to an objective. It gives the team
a shared definition of progress.

| Field   | Example                             |
| ------- | ----------------------------------- |
| Name    | Reduce median support response time |
| Start   | 18 hours                            |
| Target  | 4 hours                             |
| Current | 7 hours                             |
| Owner   | Support operations lead             |

Choose a measure that can be updated consistently. A delivery milestone can be
useful, but an outcome measure is usually stronger because it shows whether the
work changed anything.

Update progress during the objective review, and add context when a number moves
unexpectedly. Closing the related work does not automatically prove that the key
result was achieved.
