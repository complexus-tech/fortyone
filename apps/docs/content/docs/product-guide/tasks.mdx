A work item is the smallest unit of delivery in FortyOne. Your workspace may
call it a task, issue, story, or another custom term.

## Core fields

| Field                    | Use it for                                   |
| ------------------------ | -------------------------------------------- |
| Team and status          | Ownership and position in the workflow       |
| Assignee and reporter    | Who is doing the work and who requested it   |
| Priority                 | Relative urgency within the team             |
| Start and due dates      | The expected delivery window                 |
| Time needed              | The estimate used by workload and scheduling |
| Objective and key result | The outcome the work supports                |
| Sprint                   | The current delivery commitment              |
| Labels                   | Lightweight classification and filtering     |

## Create useful work

1. Write a title that describes the outcome, not only the activity.
2. Choose the team and owner.
3. Add enough context or acceptance criteria for someone else to continue.
4. Set priority and timing only when they carry a real decision.
5. Add an estimate before using workload or auto-scheduling.

Use sub-items when the pieces can be owned or completed independently. Use
links for related work that should remain separate.

## Work views

| View     | Best for                                                    |
| -------- | ----------------------------------------------------------- |
| List     | Scanning detail, grouping, filtering, and bulk updates      |
| Board    | Following flow across workflow states                       |
| Timeline | Understanding dates, overlap, and dependencies              |
| My work  | Seeing items assigned to you across teams                   |
| Calendar | Comparing planned focus time with meetings and availability |
