title: Objectives
description: Connect strategic outcomes to measurable results and delivery work.

An objective states an outcome the organization or team wants to achieve. It
should be directional enough to guide decisions and specific enough to review.

| Part        | What good looks like                          |
| ----------- | --------------------------------------------- |
| Title       | A clear outcome, not a list of activities     |
| Owner       | One person accountable for keeping it current |
| Team        | The group responsible for delivery            |
| Dates       | A realistic review window                     |
| Health      | A current assessment with context             |
| Key results | A small set of measurable signals             |
| Linked work | The delivery effort that supports the outcome |

## Review rhythm

1. Update key-result progress from evidence.
2. Review linked work, blockers, and delivery dates.
3. Set health based on the likelihood of achieving the outcome.
4. Record context when health or scope changes.
5. Close, extend, or revise the objective when the review window ends.

Keep the objective stable enough to guide work. Change the plan when needed,
but do not quietly rewrite the intended outcome to match what happened.
