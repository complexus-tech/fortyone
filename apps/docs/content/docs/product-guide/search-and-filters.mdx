---
title: Search and filters
description: Find the right work without building a permanent view for every question.
icon: Search
---

Use global search when you know part of a title, reference, person, or keyword.
Use filters when you want to narrow the current list, board, roadmap, or calendar.

| Need                          | Tool                                   |
| ----------------------------- | -------------------------------------- |
| Open a known item quickly     | Global search or command menu          |
| See one person’s active work  | Assignee and status filters            |
| Review urgent work for a team | Team, priority, and status filters     |
| Find work tied to an outcome  | Objective or key-result filter         |
| Review a delivery window      | Start-date, due-date, or sprint filter |

Combine only the filters needed to answer the question. If a useful view is
repeated often, save or share it when that option is available in the current
surface.
