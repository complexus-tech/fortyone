Maya works with the FortyOne context you can already access. It can answer
questions, summarize work, prepare plans, and propose changes without bypassing
workspace or team permissions.

## Good uses for Maya

| Need               | Example prompt                                              |
| ------------------ | ----------------------------------------------------------- |
| Find risk          | “What is blocking the launch this week?”                    |
| Prepare a plan     | “Break this objective into owned work for the next sprint.” |
| Review workload    | “Who has capacity for the documentation work?”              |
| Summarize progress | “What changed in this team since Monday?”                   |
| Schedule work      | “Find focus time for the approved launch tasks.”            |

## Review before applying

Maya can present a structured plan before it changes work. Check owners, dates,
estimates, and dependencies, then confirm only the actions you want to apply.
Important mutations may require an explicit approval even when the request was
clear.

Maya can make mistakes. Treat generated summaries and plans as working material,
and verify important operational, customer, security, or delivery decisions.
