realistic timing, and visible decisions. They can still keep their own

## The shared workflow

The subject of the work changes, but the operating pattern is usually the same:

1. Capture a request, goal, update, or decision.
2. Add the context needed to understand why it matters.
3. Give the next action an owner, priority, and realistic time window.
4. Track dependencies, approvals, and progress in one place.
5. Review the result before changing the plan or communicating an outcome.
