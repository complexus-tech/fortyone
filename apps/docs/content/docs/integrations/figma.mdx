The Figma integration turns a Figma file or frame link into structured design
context on a FortyOne work item.

| Capability        | What it provides                                    |
| ----------------- | --------------------------------------------------- |
| Rich link preview | File, frame, thumbnail, and design metadata         |
| FortyOne backlink | A direct route from Figma Dev Mode to the work item |
| Handoff status    | Ready for development and completed states          |
| Design activity   | Visibility when linked design context changes       |

## Connect Figma

1. Open **Settings → Integrations → Figma** as a workspace administrator.
2. Select **Connect Figma** and approve access for an account that can open the
   team’s design files.
3. Paste a Figma file or frame URL into a work item to attach it.
4. Confirm that the preview and handoff status are visible from both tools.

Reconnect if the Figma authorization expires or the connected account loses
access to a linked file. Disconnecting stops future refreshes but does not turn
an inaccessible design into public content.
