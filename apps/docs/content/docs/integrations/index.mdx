title: Integrations

icon: Plug
---

Integrations should remove a handoff, not create another system to maintain.
Connect a tool when the team has a clear workflow for it.

| Integration                                           | What it connects                                            | Managed by                                                 |
| ----------------------------------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------- |
| [GitHub](/integrations/github)                        | Pull requests, branches, commits, issues, and team workflow | Workspace administrator                                    |
| [Slack](/integrations/slack)                          | Conversations, work creation, previews, and Maya            | Administrator for install; members link their own accounts |
| [Google and Outlook Calendar](/integrations/calendar) | Meetings, availability, and scheduled work                  | Each member                                                |
| [Figma](/integrations/figma)                          | Design frames, handoff status, and work-item context        | Workspace administrator                                    |

GitLab and Intercom may appear as unavailable options in the product. They are
not active integrations yet and are intentionally not documented here.
